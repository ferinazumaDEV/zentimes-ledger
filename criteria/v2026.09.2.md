## 5. Words present without running JavaScript — `sin-js`

Changing · depends on whether AI crawlers run JavaScript · `technical-seo` · v2026.09.2

> Only the clear case is flagged: none = under 50 words without running JavaScript, the page arrives nearly
> empty. Above that the number is reported unrated: no data ties a word count to an outcome, so tightening it
> would be made up.

> Solo se marca el caso claro: nula = menos de 50 palabras sin ejecutar JavaScript, la página llega casi vacía.
> Por encima se informa del número sin valorar: ningún dato liga una cantidad de palabras a un resultado, así
> que endurecerlo sería inventar.

Caveat: "This is what a client that does not execute scripts receives. A low number next to a full-looking page
means the content arrives by JavaScript."
