## What can be said about this version

- It introduced the label vocabulary (`nula / baja / buena / notable / excelente`, plus an unrated state) and
  the per-check rule line. The v2026.09.1 entry lists what was tightened afterwards, so under v2026.09 the top
  label did not yet require HSTS, complete Open Graph, a matching og:locale, hreflang return links, a sitemap
  listing the page with lastmod, a linked JSON-LD graph, a heading hierarchy without skips or unique ids; and
  the image alt text check did not exist.
- The rules for words without JavaScript and for sameAs are, by the v2026.09.1 entry, unchanged since this
  version: "Only the clear case is flagged: none = under 50 words" and the sameAs rule as printed in
  [v2026.09.2.md](v2026.09.2.md), cards 5 and 8. This is inference from the history entries, not a capture:
  `needs-verification`.
- The "cookbook" the entry names is The GEO Cookbook v0.1.4 (tag of 2026-09-22), the version the four
  cross-checked cards still cite on 2026-09-23.

## Before this version: the unversioned inspector of 2026-09-22

From [`operations/03-historial-de-decisiones.md`](../operations/03-historial-de-decisiones.md), entry of
2026-09-22 (this repository, not the public page): the inspector went public on 2026-09-22 printing values and
a reproduce command next to each, with **no labels and no criteria version**. The same entry records three
published commands that did not return the number printed beside them and were fixed that day (a word count
returning 0 because a greedy pattern consumed the single-line document; a JSON-LD card printing 4 types while
its command returned 5; an `llms.txt` count reporting characters as bytes), and the rule adopted since: every
published command is executed and must return the number printed next to it. Labels, rules and the version
line arrived with v2026.09 on 2026-09-23, together with the decision to reject a 0–10 score because "the
weights would have been invented".

No command reproduces this version: the live page runs the current one. A report someone kept from v2026.09
carries no history of its own beyond the entry above; read it against v2026.09.2 knowing that "excellent" was
easier to reach and that transport and image alt text were not rated.
